# Repository instructions

This is a portable, local Zotero/Obsidian workflow. Use Python 3.11+ and the dependencies in requirements.txt. Run `python -m unittest discover -s tests -v` and compile changed Python files.

Keep fixtures synthetic. Do not add real PDFs, article fulltexts, private notes, local configuration, credentials or absolute personal paths. Preserve stable Zotero parent/PDF identity and AUTO/HUMAN ownership boundaries. Do not edit a user's installed Vault merely to update this source repository.

Skills are installable resources under skills/. Installation renders their workflow-root placeholder for the user's environment. Knowledge and retrieval instructions are independently maintained; do not copy unlicensed upstream resources.
