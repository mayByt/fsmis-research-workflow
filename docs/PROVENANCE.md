# 来源与分发边界

本项目是在个人科研阅读工作流搭建中新增的 Python 工具、通用精读模板、医学/CV 分析模块和技能指令的可迁移版本。项目维护者：mayByt。

参考 [cheneternity/Zotero-Analytical-Workflow-Skills](https://github.com/cheneternity/Zotero-Analytical-Workflow-Skills) 的 Zotero → Fulltext → Analytical Note → Knowledge 分层思路与稳定身份、相对路径等兼容约定。准备本版本时检查其 GitHub 仓库元数据及根目录，未发现 LICENSE 声明。这里不将该仓库代码或文字重新授予 MIT。

公开包排除了本地曾复制的上游知识维护/检索 Skills、配套 references、固定 Knowledge 模板和两类校验器。公开包的检索与知识维护 SKILL.md 另行编写，以现有 Vault 的格式和核验证据为准，不声称包含上游完整知识治理机制。

本项目不携带论文全文、论文页面、作者实现或任何人的私人文献库。依赖通过 requirements.txt 安装，未把第三方库源代码复制进包。用户导入的文献及其衍生阅读材料不受本项目 MIT 许可替代。
